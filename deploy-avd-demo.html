🍕 Fresh Desktop 🇮🇹 made fresh to order

One click deploys a native Azure Virtual Desktop environment—host pool, workspace, desktop app group, and one Microsoft Entra‑joined Windows 11 session host—and grants you access automatically. No domain controller, no manual RBAC. Order it, watch it bake, log in fresh.

1 Get a VM admin password ready

The portal's Basics tab will ask for a local admin password for the session host. Generate one here first — it's typed straight into this field, never sent anywhere — then paste it into the portal in Step 2.

2 Build your order & deploy

One click opens the Azure Portal's own deployment page—pre-loaded straight from the template's permanent home on GitHub, with real dropdowns for Pizza Size (VM size), Crust (Windows 11 image — 24H2, 23H2, or 24H2 + M365 Apps), and Toppings (session capacity, clipboard/drive redirection, and OS disk tier). Defaults are already picked, so Review + Create works with zero clicks—or change them live for the crowd. Every combination still deploys in the same ~18 minutes. Paste the password from Step 1 into the Basics tab when it asks.

💰 Live menu pricing — pick the same Pizza Size you'll choose in the portal's Basics tab to see what it actually costs (compute + OS disk + networking) before you click Create. Priced at the default Regular Sauce (Standard SSD) disk tier — picking Light or Extra Sauce in the portal shifts the disk line slightly.

5 Clean up when you're done

This spins up a real VM that bills by the hour. Unlike GitHub's API, Azure's own sign-in and management endpoints don't allow a webpage to call them directly from the browser (no CORS) — so this can't be a single silent click the way Deploy is. This is the fastest real alternative: type the resource group name you used in the portal, click once, and both the command is on your clipboard and Cloud Shell is open ready to paste it into.

Cloud Shell will open in a new tab — just paste (Ctrl/Cmd+V) and hit enter; it may ask you to sign in and pick a subscription/storage the first time. Prefer clicking through instead? Open Resource Groups in the Portal and delete it from there.
