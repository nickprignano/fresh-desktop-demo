4 Clean up when you're done

This spins up a real VM that bills by the hour. Unlike GitHub's API, Azure's own sign-in and management endpoints don't allow a webpage to call them directly from the browser (no CORS) — so this can't be a single silent click the way Deploy is. This is the fastest real alternative: type the resource group name you used in the portal, click once, and both the command is on your clipboard and Cloud Shell is open ready to paste it into.

Cloud Shell will open in a new tab — just paste (Ctrl/Cmd+V) and hit enter; it may ask you to sign in and pick a subscription/storage the first time. Prefer clicking through instead? Open Resource Groups in the Portal and delete it from there.
